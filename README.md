# Global Superstore Sales Dashboard

## 📊 Project Overview

This project presents an interactive sales and profitability dashboard for Global Superstore using Power BI.

The dashboard analyzes sales data and provides insights into revenue, profitability, orders, customers, market performance, monthly trends, quarterly performance, and business segments.

## 🎯 Business Objectives

- Analyze overall sales performance
- Track total profit and profit margin
- Monitor total orders and customers
- Identify yearly sales trends
- Analyze monthly sales and profit trends
- Compare sales and profit across markets
- Analyze quarterly sales performance
- Enable dynamic filtering by year, segment, and category

## 🛠️ Tools Used

- Power BI
- DAX
- Microsoft Excel

## 📌 Key KPIs

- Total Sales
- Total Profit
- Total Orders
- Total Customers
- Profit Margin

## 📈 Dashboard Features

### Sales Analysis
- Yearly Sales Trend
- Monthly Sales Trend
- Quarterly Sales Performance
- Sales by Market

### Profitability Analysis
- Total Profit
- Profit Margin
- Profit by Market
- Monthly Profit Trend

### Interactive Analysis
- Year Filter
- Segment Filter
- Category Filter
